# Browser Support

Termeh suggest use *__last versions__* of __modern browsers__ for the *best experience*. Minimum supported versions are listed below:

- __Chrome__ *__88+__* (January 2021)
- __Edge__ *__88+__* (January 2021)
- __Firefox__ *__84+__* (December 2020)
- __Safari__ *__14.1+__* (April 2021)
- __iOS Safari__ *__14.5+__* (April 2021)
- __Opera__ *__74+__* (March 2021)
- __Samsung Internet__ *__15+__* (April 2021)
- __Chrome for Android__ *__88+__* (January 2021)
- __Firefox for Android__ *__84+__* (December 2020)

*Opera Mini* and *dead browsers* are excluded from the configured targets.

The table below lists all *__CSS features__* used in Termeh along with their priority. Features marked __*High*__ are required for Termeh to work correctly.

| Feature | Supported Since | Priority |
| -- | -- | -- |
| `var()` function | 2017 Apr | __*High*__ |
| `calc()` function | 2015 Jul | __*High*__ |
| `:is` selector | 2021 Jan | __*High*__ |
| `:not` with selector lists | 2021 Jan | __*High*__ |
| Flex and flex gap | 2021 Apr | __*High*__ |
| CSS logical properties and values | 2020 Nov | Medium |
| CSS Grid | 2017 Mar | Medium |
| `aspect-ratio` property | 2021 Sep | Medium |
| `inset` property | 2021 Apr | Medium |
| `place-content` property | 2018 Jul | Medium |
| `backdrop-filter` property | 2022 Jul | Low |
| `:focus-visible` pseudo-class | 2022 Mar | Low |
| `:focus-within` pseudo-class | 2017 Mar | Low |
| `resolution` media feature | 2023 Mar | Only if use responsive mixin |
| `prefers-color-scheme` media feature | 2019 Jul | Only if use responsive mixin |
| `prefers-reduced-motion` media feature | 2019 Apr | Only if use responsive mixin |
| `prefers-contrast` media feature | 2022 May | Only if use responsive mixin |
| `dynamic-range` media feature | 2022 Feb | Only if use responsive mixin |
| `hover` and `pointer` media features | 2018 Dec | Only if use responsive mixin |
