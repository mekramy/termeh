# Core Concepts

Termeh's core powers its components, styles, and functions. It provides configurable variables and practical helpers for building consistent interfaces.

For color, the core offers tools to calculate contrast, analyze luminance, and generate palettes. Use them to create accessible, harmonious color schemes.

It also includes helpers for layout and structure, from grid and responsive utilities to text styles. These features make it easier to build flexible interfaces that scale with your project.

Explore the sections below to learn how Termeh's functions and mixins help you create modern, modular, and maintainable UIs.

- [Theming](/guide/core/scheme) — Register, retrieve, and export scoped CSS variables.
- [Global Variables](/guide/core/variable) — Use centralized, reusable variables for scoped styling.
- [Color Management](/guide/core/color) — Define, manage, and retrieve colors and variants.

- [Palette Generator](/guide/core/palette) — Generate and adjust accessible color palettes.
